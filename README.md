# ARC SUNNIES — $ARCSUN

GitHub Pages-ready static website for the ARC SUNNIES meme project on Arc.

## Official logo
The supplied logo was checked before packaging: **1536 × 1536 px, RGB**. It is preserved as `assets/arc-sunnies-logo.jpg` and also provided as an optimized **1536 × 1536 PNG** at `assets/arc-sunnies-logo.png`. The site uses the PNG for the favicon and page artwork.

## Website sections
- ARC SUNNIES hero / $ARCSUN branding
- Short Arc-focused meme project description
- Roadmap
- Gold / Bronze / Silver NFT concepts
- Planned staking + NFT-holder reward section
- Holder leaderboard UI
- Community/social placeholders ready for real links later
- Responsive mobile layout

## GitHub Pages
1. Create a GitHub repository, for example `arc-sunnies`.
2. Upload the contents of this folder to the repository root.
3. GitHub → **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save and open the generated Pages URL.

## Important
Staking, rewards, NFTs and leaderboard are currently presentation/UI concepts. Do not advertise a guaranteed APR or reward until the relevant contracts, eligibility rules and token mechanics are actually deployed and verified. Add official X/Telegram/Discord links only when they are ready.

## NFT files
Gold, Bronze, and Silver NFT PNGs are in the repository root so GitHub Pages can load them without an assets-folder path issue.
